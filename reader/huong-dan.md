# Hướng dẫn nhanh: Trợ lý đọc

Đây là tài liệu mẫu. Bấm nút đọc màu cam ở dưới, hoặc phím cách, để nghe thử. Mặc định em đọc bằng giọng nam Nam Minh, anh đổi sang giọng nữ Hoài My ở ô chọn giọng.

## Đưa tài liệu vào

- Bấm Mở file để chọn file txt, md, pdf, docx, html hoặc epub. Kéo thả file vào cửa sổ này cũng được.
- Bôi đen một đoạn ở bất kỳ đâu, bấm Ctrl C, rồi bấm Từ clipboard. Nếu thứ vừa copy là một link web hay một đường dẫn file, trợ lý sẽ tự mở link hoặc file đó.
- Bấm Dán hoặc link để dán văn bản dài, đường dẫn file trên máy, hoặc link bài báo.
- Kéo một file thả thẳng lên biểu tượng Start Doc Reader cũng mở được luôn.

## Khi đang nghe

- Phím cách để đọc hoặc tạm dừng. Mũi tên trái phải để lùi hoặc tới một câu. Giữ Shift để nhảy cả đoạn.
- Bấm vào câu bất kỳ để đọc từ câu đó.
- Nút tai nghe và phím media trên bàn phím cũng điều khiển được.
- Tài liệu nào cũng tự nhớ đang nghe tới đâu. Mở lại là nghe tiếp.

## Khi có thắc mắc

Bấm phím Q để đặt câu hỏi ngay tại câu đang đọc. Bấm phím N để ghi chú. Trợ lý sẽ tự dừng lại, anh nói hoặc gõ nội dung, rồi bấm Ctrl Enter để lưu. Lưu xong trợ lý đọc tiếp.

Muốn nói thay vì gõ, bấm biểu tượng micro trong ô ghi chú, hoặc dùng Voice Mic như bình thường.

Bôi đen một đoạn trong tài liệu sẽ hiện thanh công cụ nhỏ để ghi chú, hỏi, hoặc đọc từ đoạn đó.

## Ghi chú được lưu ở đâu

Mỗi tài liệu có một file ghi chú Markdown riêng trong thư mục reader-data, notes. File này ghi rõ câu được trích, ngữ cảnh đoạn văn, và các câu hỏi chưa rõ.

Bấm Copy để hỏi Claude, rồi dán vào Claude. Claude sẽ đọc file ghi chú và trả lời từng câu hỏi. Có câu trả lời rồi thì bấm Ghi trả lời ở câu hỏi đó để lưu lại và nghe lại sau.
