Đưa tài liệu vào, tôi đọc cho anh nghe

Kéo thả file vào đây, bấm Mở file, hoặc bôi đen và Ctrl+C một đoạn ở bất kỳ đâu rồi bấm Từ clipboard.

  • Định dạng: txt, md (Obsidian), pdf, docx, html, epub, link web, Google Docs công khai.
  • Đang nghe mà thắc mắc: bấm Q để đặt câu hỏi, N để ghi chú. Nhập bằng giọng nói được luôn.
  • Ghi chú lưu thành file Markdown, mở lại hoặc đưa cho Claude đọc và trả lời.
